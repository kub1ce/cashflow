# CashFlow - Десктопное приложение для управления личными финансами

**CashFlow** - это приватный, полностью автономный инструмент для долгосрочного финансового планирования и учета расходов, построенный на базе архитектуры недельной гранулярности. Приложение позволяет прогнозировать кассовые разрывы на 52 недели вперед, гарантируя 100% конфиденциальность ваших данных без привязки к облакам или банковским API.

---

## Ключевые особенности

*   **Недельное планирование (52 недели):** Динамическая генерация периодов от любой выбранной даты с возможностью сквозного прогнозирования баланса.
*   **100% Приватность и Безопасность:** Локальное хранение данных в SQLite. Безопасность на уровне ORM (защита от SQL-инъекций) и встроенная валидация от случайного сброса периодов.
*   **Оптимистичный UI:** Мгновенный отклик интерфейса (DOM-дерево обновляется до получения ответа от БД) и бесшовная регенерация таблиц без перезагрузки страниц.
*   **Стек отмены действий (Undo):** Полноценная история изменений на 50 шагов (`Ctrl+Z`) для безопасного редактирования любых ячеек.
*   **Управление кассовыми разрывами:** Автоматическое планирование возврата займов, расчет обязательных платежей и визуализация дефицита бюджета со стратегиями его устранения.
*   **Надежная связность:** Каскадное удаление связанных планов и фактов при изменении структуры периодов с автоматическим созданием резервной копии данных.

---

## Технологический стек

Приложение разработано без использования тяжелых внешних СУБД или громоздких фреймворков:

*   **Backend:** Python, SQLAlchemy 2.0 (встроенная база данных SQLite)
*   **Frontend:** Vanilla JS, HTML5, CSS3 (более 80 нативных анимаций, shake-эффекты для некорректного ввода, динамический скролл)
*   **Связующий слой (Desktop):** PyWebView (нативное десктопное окно + JS Bridge API, включающее более 40 методов)

---

## Архитектура данных

Продукт оперирует шестью ключевыми сущностями:
1.  **Счета** - карты, наличные, депозиты с начальным балансом.
2.  **Категории** - настраиваемый справочник категорий (тип, цвет, эмодзи).
3.  **План** - прогнозные значения по категориям на каждую из 52 недель.
4.  **Факт** - реальные транзакции, связанные со счетами и категориями (с защитой от дублей).
5.  **Настройки** - параметры планирования и выбранная стратегия дефицита.
6.  **Комментарии** - контекстные заметки к ячейкам финансовой таблицы.

## Быстрый старт

### Для пользователей (Windows)
Самый простой способ начать работу - использовать готовый исполняемый файл:
1. Перейдите в раздел **[Releases](https://github.com/kub1ce/cashflow/releases)** на GitHub.
2. Скачайте последнюю версию `CashFlow.exe`.
3. Запустите приложение. 

*При первом запуске автоматически откроется **Мастер первого запуска** для генерации локальной базы данных и настройки профиля.*

---

### Для разработчиков (Запуск из исходного кода)
Если вы хотите изучить архитектуру приложения или внести свои изменения, проект можно запустить локально.

**Требования:**
* Python 3.10+

**Инструкция по установке:**
1. Клонируйте репозиторий:
```bash
git clone https://github.com/kub1ce/cashflow.git
cd cashflow
```
2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate
```
3. Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```
4. Запустите проект
```bash
python main.py
```
